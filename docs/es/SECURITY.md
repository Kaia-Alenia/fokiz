# Política de Seguridad

### Versiones Soportadas
Solo la última versión mayor de Fokiz recibe actualizaciones de seguridad.

| Versión | Soportada          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

### Reportar una Vulnerabilidad
La seguridad es muy importante para nosotros en Alenia Studios. Si descubres una vulnerabilidad de seguridad en Fokiz, por favor NO abras un issue público.

En su lugar, envía un correo electrónico a **contact.aleniastudios@gmail.com**. Revisaremos tu reporte y responderemos lo antes posible.
