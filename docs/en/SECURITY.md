# Security Policy

### Supported Versions
Only the latest major version of Fokiz is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

### Reporting a Vulnerability
Security is very important to us at Alenia Studios. If you discover a security vulnerability in Fokiz, please DO NOT open a public issue.

Instead, please send an email to **contact.aleniastudios@gmail.com**. We will review your report and respond as quickly as possible.
