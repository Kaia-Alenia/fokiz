# Contributing to Fokiz / Contribuir a Fokiz

[English](#english) | [Español](#español)

---

## English

Thank you for your interest in contributing to Fokiz! We welcome contributions to make this focus tool even better.

### How to Contribute
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. **Create a branch** for your feature or bug fix (`git checkout -b feature/my-feature`).
4. **Make your changes** following the code standards.
5. **Run tests** (`pytest`) to ensure nothing is broken.
6. **Commit and push** to your fork.
7. **Submit a Pull Request** against the `main` branch.

### Code Standards
- Code must be written in English.
- Use Python 3.10+ typing hints.
- Keep things simple and minimal (no unnecessary external dependencies).
- Follow the Alenia Studios code guidelines (GNU GPL v3 licensed).

## Español

¡Gracias por tu interés en contribuir a Fokiz! Apreciamos las contribuciones para hacer esta herramienta de concentración aún mejor.

### Cómo Contribuir
1. **Haz un Fork del repositorio** en GitHub.
2. **Clona tu fork** localmente.
3. **Crea una rama** para tu nueva funcionalidad o corrección (`git checkout -b feature/mi-funcionalidad`).
4. **Realiza tus cambios** siguiendo los estándares de código.
5. **Ejecuta las pruebas** (`pytest`) para asegurar que nada se ha roto.
6. **Haz commit y push** a tu fork.
7. **Abre un Pull Request** hacia la rama `main`.

### Estándares de Código
- El código y los comentarios críticos deben escribirse en Inglés.
- Usa tipado estático (typing hints) de Python 3.10+.
- Mantén el código simple y minimalista (sin dependencias externas innecesarias).
- Sigue las directrices de Alenia Studios (Licencia GNU GPL v3).
